// What It Does

Built for how you
actually work

📋

Structured Templates

Copy a purpose-built prompt into Claude or ChatGPT. The AI already knows your project name, engine version, and what it's building. No more re-explaining from scratch.

⚡

Parsed Output

Paste the AI's response back into LogicSmith. It extracts variables, components, functions, and connections into a clean, readable format you can actually use.

📖

Dev Diary

Every Blueprint you generate gets saved to your project diary. Never lose your instructions again. Reference, review, and build on your work session after session.

🐍

Python Scaffolder

LogicSmith generates a Python script for every Blueprint. Run it directly in Unreal Engine to scaffold your Blueprint structure automatically.

🗺️

Implementation Plan

From your Game Design Document to a full phase-by-phase build plan. Know exactly what to build, and in what order — before you write a single node.

⬡

Standalone Mode

Don't need a full project? Use the standalone utility for one-shot Blueprint instructions on any asset, any time — saved to your personal repository.
